# AI Assistant

An intelligent voice-enabled AI Assistant inspired by Google Assistant, designed to help users perform tasks, answer questions, and interact naturally through voice or text commands.

## Features

- 🎙️ Voice command recognition
- 💬 Natural language conversation
- 🔍 Real-time information retrieval
- 📅 Task and reminder management
- 🌦️ Weather updates
- 📰 News and general knowledge queries
- ⚡ Fast and responsive interactions
- 🔊 Text-to-speech responses

## Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Speech Processing: Speech-to-Text & Text-to-Speech APIs

## Installation

```bash
git clone <repository-url>
cd ai-assistant
